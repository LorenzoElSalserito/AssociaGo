# 16. Amtliche Unterschriften

Die Unterschriften werden unter **Einstellungen › Unterschriften** verwaltet. Es gibt drei Registerkarten, eine pro Rolle: **Präsident**, **Sekretär** und **Schatzmeister**.

## 16.1 Name und Titel

In jeder Registerkarte:
- **Name**: Vor- und Nachname der Person, die das Amt innehat;
- **Titel**: bereits mit dem Namen der Rolle ausgefüllt, Sie können ihn ändern (z. B. „Präsident des Vorstands“).

Sobald Sie ein Feld ändern, erscheint die Schaltfläche **Speichern**. Klicken Sie darauf: Die Bestätigung lautet „Unterschrift erfolgreich gespeichert.“.

## 16.2 Unterschriftsbild

Das Feld **Unterschriftsbild hochladen** erscheint erst, nachdem der Name mindestens einmal gespeichert wurde (bis dahin weist die Registerkarte darauf hin: „Speichern Sie zuerst den Namen, dann laden Sie das Bild hoch.“).
1. Klicken Sie auf das Feld und wählen Sie eine PNG- oder JPG-Datei (transparenter Hintergrund empfohlen).
2. Das Bild wird sofort hochgeladen, ohne weitere Schaltflächen, und erscheint in der Vorschau.

Zum Entfernen klicken Sie auf **Löschen** unter der Vorschau. Gibt es kein Bild, zeigt die Registerkarte **Kein Unterschriftsbild**.

Es gibt keinen Status aktiv/inaktiv: Eine Unterschrift ist vorhanden oder nicht.

## 16.3 Wo sie verwendet werden

Die hier gespeicherten Unterschriften werden in die PDFs gedruckt: das Bild, ohne Verzerrung skaliert, über einer Zeile mit dem Namen und darunter das Amt (der **Titel**, falls ausgefüllt, sonst der Name der Rolle in der Sprache der Oberfläche).
- **Jahresabschluss**: Präsident, Sekretär und Schatzmeister.
- **Zertifikate**: die in der Registerkarte **Unterzeichner** der Vorlage gewählten Rollen.
- **Versammlungsprotokolle**: Präsident und Sekretär. Das Bild erscheint nur, wenn der in der Versammlung angegebene Name mit dem der Unterschrift übereinstimmt; andernfalls bleibt die leere Zeile für die handschriftliche Unterschrift.

Ist für eine Rolle keine Unterschrift gespeichert, verwendet das PDF den im **Organigramm** (Einstellungen › Vereinsprofil) angegebenen Namen und lässt die Zeile leer. Auch ein unlesbares Bild wird ignoriert, ohne das Dokument zu blockieren.

> Die Unterschriften sind Bilder: Sie haben nicht den Wert einer qualifizierten elektronischen Signatur (eIDAS). Für Dokumente, die eine solche erfordern, verwenden Sie ein zertifiziertes Werkzeug für elektronische Signaturen.
